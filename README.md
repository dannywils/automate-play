# Merit

**[Play in your browser](https://dannywils.github.io/automate-play/)**

A little help. Then a little more.

Merit is an eight-day office game about work, trust and automation. Complete tasks on a physical computer, decide what to hand over to the assistant, and see how the office changes.

## Playing

Use a desktop browser with WebGL 2, a mouse and keyboard. Click **Play Merit**, then **Begin**, then click the monitor. Open **Task List** to start an assignment. Tasks use clicks and drags; there is no typing requirement. From Day 2, drag the assistant onto supported work to request help. Press Escape for settings, controls and saving.

The first visit downloads about 190 MiB of game resources. Audio starts after interacting with the page. Progress stays in this browser profile; clearing site data clears saves. This build is intended for desktop play; mobile touch play has not been qualified.

The game includes firearm imagery and a gunshot in its final sequence.

## Distribution

This repository holds the Pages deployment workflow and compiled browser releases. The editable Godot project and development history are maintained privately. Releases contain only the static game distribution and third-party notices; no personal saves, development captures or source project is uploaded here.

Third-party credits are available from the game's opening screen and [THIRD-PARTY.txt](https://dannywils.github.io/automate-play/THIRD-PARTY.txt). The public edition uses a CC0 gunshot recording. The game itself is not offered under a blanket open-source license.

Each release archive has a SHA256 in its release notes and a per-file `site-manifest.json`. Publishing a release deploys it to Pages. An owner can redeploy any prior release through **Actions → Deploy browser game → Run workflow**.
